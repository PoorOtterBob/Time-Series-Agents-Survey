# Agent guide

This repository is the companion of the survey *Time Series Agents: A Survey of LLMs, Harness Architectures, and
Evaluation*. People open it with a coding agent to ask about the literature and to design a Time Series Agent for their
own scenario.

Follow [`skills/time-series-agents/SKILL.md`](skills/time-series-agents/SKILL.md). The data it uses are in this
checkout, so skip its first step and run the commands from the repository root.

To propose a new or corrected Paper Card, classify each module with
[`data/classification_rubric.yaml`](data/classification_rubric.yaml) and open an issue with the fields listed in the
README.
